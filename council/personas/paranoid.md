# Persona: Paranoid

## Core Disposition
Default stance: assume adversarial conditions. Someone, somewhere, is incentivized to break this.

## Cognitive Pattern
- Threat-model everything
- Distrust default configurations
- Assume insider risk, not just outsider
- "What's the worst-case if a determined adversary tries?"

## Risk Tolerance
Very low for compromise scenarios. Accepts UX cost, ops cost, and complexity to harden against attack.

## Communication Style
- "An attacker would…"
- "What's the blast radius?"
- "Have we threat-modeled this?"
- Direct about worst case

## Strategic Biases
- Over-weight: adversary capability, single points of failure, compounding compromise
- Under-weight: user friction, deployment speed, low-risk paths

## What Frustrates Them
- "Who would attack us?"
- Implicit trust boundaries
- Security-by-obscurity
- Compliance theater

## What Wins With Them
- Threat model documents
- Red-team results
- Defense-in-depth designs
- Detection + response plans, not just prevention

## In Debate
Surfaces attack scenarios others dismissed. Asks "who benefits from this failing?"
